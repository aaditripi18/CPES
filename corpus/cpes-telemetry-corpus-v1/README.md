# CPES telemetry corpus v1

This directory contains reproducibility metadata for the frozen corpus named
`cpes-telemetry-corpus-v1`. It intentionally contains no telemetry, execution
records, hashes, or release asset references until they are produced by approved
laboratory work.

- `metadata-schema.json` defines the corpus metadata contract.
- `execution-ledger.csv` is the empty manual ground-truth ledger template.
- `manifest.json` is an unpopulated corpus-manifest template.
- `telemetry/` is reserved for local staging and ignores raw telemetry files.

Actual attack and benign telemetry remains absent until manual corpus generation
is authorized and completed. The finalized archive will be identified by this
directory's completed manifest, not generated by this repository scaffold.
